# Lawr's Burgers — PDF Design Recreation

This is a vanilla HTML/CSS/JS recreation of the supplied two-page Lawr's Burgers design.

## Run it in VS Code

1. Put the `lawrs-burgers-site` folder anywhere on your computer.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Use Live Server if you have it installed, or open `index.html` directly in a browser.

## Structure

- `index.html` — page markup/content
- `css/style.css` — layout, typography, colors, responsive behavior
- `js/script.js` — mobile navigation, current year, small reveal animation
- `assets/` — image assets extracted from the supplied PDF

The page is intentionally built with plain HTML/CSS/JavaScript so it can be copied directly into a normal VS Code web project.
